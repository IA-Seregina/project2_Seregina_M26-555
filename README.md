# Управление таблицами

Программа позволяет создавать, удалять таблицы, просматривать список существующих таблиц. Информация о таблицах и их столбцах сохраняется в файле `db_meta.json`.

Поддерживаемые типы данных при создании: `int`, `str`, `bool`. ID всегда иммет тип `int`.

## Команды

- `create_table <имя_таблицы> <столбец:тип> ...` — создание таблицы
- `drop_table <имя_таблицы>` — удаление таблицы
- `list_tables` — список таблиц
- `help` — справка по командам
- `exit` — выход из программы


## Пример использования

Запуск программы:

```text
database
```

Создание таблицы:

```text
Введите команду: create_table books name:str author:str has_multiple_volumes:bool
Таблица 'books' успешно создана со столбцами: ID:int, name:str, author:str, has_multiple_volumes:bool
```

Просмотр списка таблиц:

```text
Введите команду: list_tables
- books
```

Удаление таблицы:

```text
Введите команду: drop_table books
Таблица 'books' успешно удалена.
```

# CRUD-операции

В программу были добавлены следующие операции:

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавление записи в таблицу
- `select from <имя_таблицы> [where <столбец> = <значение>]` — просмотр всех записей или выборка по условию
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` — обновление записей по условию
- `delete from <имя_таблицы> where <столбец> = <значение>` — удаление записей по условию

## Пример использования

Добавление записи:

```text
Введите команду: insert into books values (Harry_Potter, Rowling, true)
```

Просмотр всех записей:

```text
Введите команду: select from books
```

Просмотр записей по условию:

```text
Введите команду: select from books where author = Rowling
```

Обновление записи:

```text
Введите команду: update books set has_multiple_volumes = false where author = Rowling
```

Удаление записи:

```text
Введите команду: delete from books where author = Rowling
```

# Декораторы 

Были добавлены декораторы для выполнения следующих функций:

- **Обработка ошибок** — декоратор `handle_db_errors` перехватывает `KeyError`, `ValueError` и `FileNotFoundError`, предотвращая аварийное завершение программы и выводя сообщение об ошибке.
- **Подтверждение действий** — декоратор `confirm_action` запрашивает подтверждение перед удалением таблицы (`drop_table`) или записей (`delete`). Операция выполняется только при вводе `y`, иначе отменяется.
- **Замер времени выполнения** — декоратор `log_time` измеряет время выполнения операций `insert` и `select` с помощью time.monotonic().
- **Кэширование запросов** — функция `create_cacher` использует замыкание для хранения результатов `select`. При повторном запросе с одинаковыми данными и условиями результат возвращается из кэша без повторной фильтрации.

## Пример использования

Подтверждение удаления таблицы:

```text
Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

Отмена удаления записей:

```text
Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: n
Операция отменена.
```
