# Управление таблицами

Программа позволяет создавать, удалять таблицы, просматривать список существующих таблиц. Информация о таблицах и их столбцах сохраняется в файле `db_meta.json`.

Поддерживаемые типы данных при создании: `int`, `str`, `bool`. ID всегда иммет тип `int`.

## Команды

- `create_table <имя_таблицы> <столбец:тип> ...` — создание таблицы
- `drop_table <имя_таблицы>` — удаление таблицы
- `list_tables` — список таблиц
- `help` — справка по командам
- `exit` — выход из программы


## Пример использования

Запуск программы:

```text
database
```

Создание таблицы:

```text
Введите команду: create_table books name:str author:str has_multiple_volumes:bool
Таблица 'books' успешно создана со столбцами: ID:int, name:str, author:str, has_multiple_volumes:bool
```

Просмотр списка таблиц:

```text
Введите команду: list_tables
- books
```

Удаление таблицы:

```text
Введите команду: drop_table books
Таблица 'books' успешно удалена.
```
